# HIPAA Security Audit Assistant

A retrieval-augmented assistant that reads an organisation's security policy (PDF, DOCX, TXT or Markdown) and checks it against
the HIPAA Security Rule. For every control it returns one of three statuses, **met**, **partial** or **gap**, together with
evidence quotes that the server has verified against the source document.

Status: work in progress. The full README, architecture notes and limitations are added as the build lands.

> This tool supports a review of policy documents. It is not legal advice and not a compliance certification.
